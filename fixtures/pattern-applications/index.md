# Pattern Application

- [Health endpoints apply to billing](health-endpoints.md) - Billing adopts the health-endpoint standard and binds each criterion to a local probe check.
- [Behavior conformance does not apply to billing](behavior-conformance.md) - Billing publishes no generated behavior conformance report, so the behavior-conformance pattern does not govern it.
- [Structured logging exception for billing](structured-logging.md) - Billing accepts a bounded exception to the structured-logging standard during its logger migration.
- [Request tracing for billing awaits triage](request-tracing.md) - Nobody has yet decided whether the request-tracing pattern governs billing.
