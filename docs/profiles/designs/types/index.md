# OKF Profile Type

- [Breadboard](breadboard.md) - How the surface works, before what it looks like: places, the affordances in each, the connections between them, and what each viewer gets.
- [Design Brief](design-brief.md) - Why the surface exists and what it must achieve: the problem, who views it and for which jobs, the states the thing shown can be in, the outcomes it should move, the constraints, the scenarios it must work in, and the criteria it is judged by. No structure, no layout.
- [Detailed Design](detailed-design.md) - What the breadboard looks like and how it behaves: the chosen direction, layouts, visual hierarchy, components, interaction details and every affordance state, with the final screens.
