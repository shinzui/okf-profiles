# OKF Profile

- [friction-log](profile.md) - The cost of doing work in a repository, recorded before it is known to be a defect or a request: one entry per surface that cost an implementer effort, with a stable FRIC handle, an impact graded by what happened to the work, the kind of surface, who felt it and whose surface it was, and a triage status naming the artifact that took it over. Behavior known to be wrong is a bug report; a gap someone can state is an improvement request.
