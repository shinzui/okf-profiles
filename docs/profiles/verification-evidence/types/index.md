# OKF Profile Type

- [Attestation](attestation.md) - A deterministic verifier fetched a record's data, re-checked it, and this is what it concluded.
- [Attested Computation](attested-computation.md) - How one outcome, verdict or figure is computed from raw run data, and how a deterministic verifier re-checks it.
- [Verification Run](verification-run.md) - One recorded run, or one recorded comparison of runs: what ran, against what, where, with which outcome, and where the data is.
