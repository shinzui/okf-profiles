# OKF Profile Type

- [Explanation](explanation.md) - Conceptual material that builds understanding, context, and decision-making judgment.
- [Guide](guide.md) - Goal-oriented instructions that help a reader complete a specific task.
- [Navigation](navigation.md) - A curated entry point that routes readers to the right documentation.
- [Reference](reference.md) - Authoritative lookup material describing interfaces, contracts, options, or current state.
- [Runbook](runbook.md) - An operational procedure whose ordering, safety conditions, and recovery behavior matter.
- [Tutorial](tutorial.md) - A learning-oriented sequence that helps a reader gain initial working experience.
